교수 화면 구현 기능\
1\. 내 지도 현황\
교수는 아래 정보를 확인·수정한다.\\

- 지도 가능 여부: 모집 중 / 마감
- 지도 정원
- 현재 배정 인원
- 남은 자리
- 연구 분야·키워드
- 선호 연구 주제

정원은 현재 배정 인원보다 작게 설정할 수 없다.\
2\. 지도 신청 목록\
교수는 신청 학생 목록을 확인한다.\\

- 학생명
- 소속·전공
- 졸업예정학기
- 신청 연구 주제
- 간단한 연구계획
- 신청일
- 현재 상태

신청 상태는 대기, 수정 요청, 면담 요청, 승인, 반려로 표시한다.\
3\. 신청 검토·처리\
교수는 신청 상세 화면에서 아래 중 하나를 선택한다.\\

- 승인
- 수정 요청
- 면담 요청
- 반려

수정 요청·면담 요청·반려 시에는 학생에게 전달할 피드백을 입력한다.\
4\. 승인 처리 규칙\
교수가 승인하면 다음이 함께 변경된다.\\

- 교수의 현재 배정 인원이 1명 증가
- 학생 신청 상태가 승인으로 변경
- 학생 화면의 다음 행동이 연구계획서 제출로 변경

남은 자리가 0명인 경우 승인 버튼을 비활성화한다.\
5\. 교수 화면 데모\\

1. 교수는 대기 중인 지도 신청을 확인한다.
2. 학생의 연구 주제와 계획을 검토한다.
3. 신청을 승인한다.
4. 현재 배정 인원과 남은 자리가 갱신된다.
5. 학생 화면에서 지도교수 배정 완료를 확인한다.
