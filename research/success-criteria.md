# 졸업논문 통합 안내·지도교수 관리 서비스 성공기준

작성일: 2026-09-21

## 목표와 범위

학생이 여러 학과의 공지를 따로 해석하지 않아도 자신의 전공별 졸업논문 요건, 다음 할 일, 마감, 지도교수 확보 상태를 확인하고, 행정실은 학과별 규칙과 교수별 정원을 반영해 안내와 배정 현황을 관리할 수 있게 한다.

대상: 경제학부, 심리학과, 기계공학부, 중어중문학과, 생명과학부. 학생 조회와 행정실 관리 기능 모두 포함. 사용자가 제시한 2시간은 개발 시제품의 범위와 우선순위에 반영한다. 이번 작업의 산출물은 성공기준이며 개발 자체가 아니다.

아래 수치와 검증 시나리오는 개발 합격 여부를 판단하기 위한 제안이다. 실제 사용자 실험이나 행정실 승인을 이미 받은 결과가 아니다.

| A5 미완료 학생 확인 | 행정실이 미신청, 확인·배정 대기, 확정 상태를 필터링하고 다음 조치 대상을 찾는다. | ‘지도교수 미확정’ 필터에서 확정 학생은 제외되며 각 학생의 전공과 대기 이유가 보인다. |
| A6 학생·행정실 상태 일치 | 행정실의 배정 확정과 안내 변경이 학생 조회 결과에 반영되고 새로고침 후에도 유지된다. | 행정실에서 배정한 뒤 학생 화면과 새로고침 결과의 교수·상태·정원이 일치한다. |

정원 계산 원칙: 잔여 정원 = 총 정원 - 유효한 확정 배정 수. 신청 중·반려·취소는 확정 인원에 포함하지 않는 것을 기본 제안으로 한다. 신청 시 좌석을 예약하는 정책이 필요하면 별도 상태·만료 규칙을 먼저 결정한다.

## 2시간 시제품의 통합 시연 합격 조건

1. 다전공 학생이 본인 조건을 선택하고 두 학과의 다음 행동과 마감을 확인한다.
2. 행정실이 교수 정원을 설정하고 미확정 학생을 조회한다.
3. 정원 내 배정은 성공하고 정원을 넘는 배정은 차단된다.
4. 배정 결과가 학생 화면에 나타나며 다른 전공의 상태는 유지된다.
5. 행정실이 공지 기한을 수정하면 학생 화면에 변경이 반영된다.
6. 다섯 학과를 모두 선택할 수 있고, 확보하지 못한 규칙은 ‘확인 필요’로 정직하게 표시한다. 시연용 교수·학생·정원은 가상 데이터임을 명시한다.

S1~S5, A1~A6과 위 시나리오를 모두 통과해야 핵심 시제품 성공으로 판정한다. 화면만 존재하거나 버튼이 상태를 바꾸지 않으면 통과가 아니다. 실제 외부 이메일·eTL 제출 완료와 서비스 내 체크 완료를 혼동하지 않는다.

## 사용성과 도입 효과 검증 — 개발 이후

- 다전공 학생 5명 중 4명 이상이 별도 설명 없이 1분 내 두 전공의 다음 행동·마감·지도교수 상태를 정확히 찾는 것을 목표로 한다.
- 행정실 담당자 또는 업무를 설명받은 대리 평가자가 3분 내 정원 수정, 미배정 조회, 배정 확정, 공지 수정 시나리오를 완료하는 것을 목표로 한다. 대리 평가 결과를 실제 행정실 검증으로 표기하지 않는다.
- 기존 게시판·이메일 방식과 같은 사례로 비교해 소요 시간과 누락 건수를 기록한다. 개선 효과는 측정 후에만 주장한다.
- 실제 운영 전에는 다섯 학과 담당자가 해당 학기 요건·배정 정책·정원 단위를 검토해야 한다. 로그인·학과별 권한·학생 정보 접근 제한·동시 배정의 원자적 처리도 운영 합격 조건이다. 역할 전환만 있는 시제품을 실제 권한 관리로 간주하지 않는다.

## 아직 결정이 필요한 사항

1. 희망 교수 순위를 받을지, 받는다면 몇 순위까지인지. ‘1~3순위’는 제안이며 확정 요구가 아니다.
2. 교수 직접 수락 화면을 포함할지, 행정실이 확인 결과를 반영할지.
3. 교수 정원의 단위: 학기별 신규 지도 학생인지, 현재 지도 중인 전체 학생인지, 공동·타전공 지도를 어떻게 계산할지.
4. 정원 초과 신청의 우선순위·대기·재신청 정책. 자동 배정이나 선착순은 승인된 정책이 없어 필수 기능으로 정하지 않는다.

이 결정들은 구현 세부사항 확정에 필요하다. 개인화 안내, 근거 표시, 상태 분리, 정원 초과 방지라는 성공기준은 어느 방식을 선택해도 유지된다.
