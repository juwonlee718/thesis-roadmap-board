# 서울대학교 학부 졸업논문 안내 비교 — 사전 조사

확인일: 2026-09-21. 대상은 경제학부·심리학과·기계공학부·중어중문학과·생명과학부이며 학생 조회와 행정실 관리 기능을 모두 포함한다. 사용자 제시 기한은 2시간이다. 지도교수 할당을 중요 문제로 추가 제시했으며 구체적 문제와 처리 범위는 답변 대기 중이다. 아래 초기 표본 중 산업공학과·수리과학부는 참고 사례일 뿐 개발 대상이 아니다. 지난 학기 안내는 절차 비교에만 사용한다. 공개 게시판이 언급한 이메일 안내의 실제 내용은 확보하지 않았다.

## 요구사항 가설 — 아직 사용자 확정 전

학생은 전공별로 전공 유형(주전공·복수전공·부전공 등), 입학연도, 졸업 예정 학기를 지정한다. 적용되는 절차를 전공별로 구분하면서 하나의 일정표에서 확인한다. 공지별 적용 시기가 다르면 서로 다른 학기의 요건을 합치지 않는다.

행정실에는 공지의 내용을 공통 항목으로 정리한 초안을 제공하고, 담당자가 검토한 내용과 수집만 된 내용을 구분하는 방안을 제안할 수 있다. 이는 확정 기능이 아니다. 실제 행정실의 업무 방식과 수정 권한을 확인해야 한다.

공통 수집 항목 후보: 학과, 전공 유형, 입학연도 조건, 졸업 시기, 논문·대체요건, 단계, 선행 단계, 제출물, 제출 방식, 제출처, 서명 필요 여부, 시작·마감 시각, 서식 링크, 예외, 원문 링크, 확인일, 검토 상태.

## 개발 전 확인할 질문

1. 지도교수 할당 문제는 학생의 직접 연락, 신청 편중, 행정실 취합 부담, 배정 상태 확인 중 어디에 있는가?
2. 이미 결정된 지도교수 등록·확인인가, 희망 신청부터 수락·배정까지인가?
3. 사용자가 알고 있는 실제 학과 배정 사례는 무엇인가?
4. 행정실이 직접 정보를 관리할 수 있는지, 게시판을 유지하면서 검토만 하는 방식을 원하는지?

## 미확인 사항

- 지도교수 할당 기능의 구체적 범위와 문제 사례에 대한 사용자 답변
- 대상 학과 전체의 동일 졸업 시기 최신 공지
- 첨부파일 원문 내용과 이메일 전용 안내
- 논문 대체요건, 부전공 예외의 학과별 상세 규칙
- 실제 행정실 의견과 운영 주체

현재 개발이나 외부 게시·전달은 시작하지 않았다.
